# Fortune Cookie for the Liquidated Trader

A make.fun bounty entry. The program writes one fortune cookie line for a
crypto trader who just got liquidated to `/output/entry.txt`.

The line opens with the classic lucky-numbers formula, then breaks it with
the one number that matters to the trader, and lands on a small, rueful note
of hope instead of a lecture.

## Entry

> Your lucky numbers are 3, 7, and 42. None of them is your liquidation price, which is a start.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` sets the output directory (default `/output`).
